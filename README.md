# 대구 아파트 인사이트

대구광역시 구·군·동별 아파트 시장과 수성푸르지오리버센트 가격을 살펴보는 정적 웹 대시보드입니다.

## 주요 기능

- 지역·기준월·면적·조회기간 연동 필터
- 매매·전세·월세 가격지수 및 단지 랭킹
- 수성푸르지오리버센트 면적별 가격 분석
- 중동 주변 아파트 비교
- OpenStreetMap 연동 지도

## 배포

`main` 브랜치에 변경사항을 푸시하면 GitHub Actions가 `dist` 폴더를 GitHub Pages에 배포합니다.

> 화면의 일부 값은 UI 시연용 샘플입니다. 실제 의사결정 전 국토교통부 실거래가 원문을 확인하세요.
